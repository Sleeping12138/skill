# 飞书稿中等篇幅调整设计

## 目标

在不恢复长篇技术手册和慢速内容验收的前提下，让 8 份飞书文档提供足够的背景、机制和实际上手指引。

## 设计

- 00–06 每篇建议约 600–900 个中文字。
- 07 架构深读建议约 900–1400 个中文字。
- 每篇包含：用途/背景、4–6 个关键结论、必要机制、一个真实例子、少量关键路径，以及下一步阅读或排障入口。
- 图只在明显帮助理解关系或顺序时保留。
- 所有字数都是写作建议，不进入验证器；不新增模型自评或远端回读。

## 验收

Skill 和改写契约使用相同篇幅参考，验证脚本不包含字数或图数门禁，原有轻量测试继续通过。
